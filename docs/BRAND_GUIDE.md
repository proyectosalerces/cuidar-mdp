### 1.6 Tono de Voz

**Principios generales:**
- Cercano pero profesional
- Empático sin ser condescendiente
- Informativo sin ser abrumador
- Positivo sin minimizar la dificultad
- Inclusivo, usando lenguaje accesible

**Ejemplos de Tono ✅ SÍ / ❌ NO:**

| Contexto | ✅ SÍ (así hablamos) | ❌ NO (así no) |
|----------|----------------------|----------------|
| Bienvenida | "Estamos acá para acompañarte en esta búsqueda" | "¡Bienvenido a la mejor web de geriátricos!" |
| Describir servicio | "Te ayudamos a encontrar la residencia que mejor se adapte a las necesidades de tu familiar" | "Somos los número uno en consultoría geriátrica premium" |
| Situación difícil | "Sabemos que es una decisión importante y muchas veces difícil" | "¿Tu viejo no puede vivir solo? Nosotros te salvamos" |
| CTA (call to action) | "Contanos tu situación y te orientamos sin compromiso" | "¡COMPRÁ AHORA! ¡OFERTA LIMITADA!" |
| Blog | "En esta guía te explicamos paso a paso cómo evaluar una residencia" | "Lea el siguiente artículo informativo sobre evaluación residencial geriátrica" |
| Datos de contacto | "Escribinos por WhatsApp cuando quieras, te respondemos lo antes posible" | "Contacte a nuestro departamento de atención al cliente" |
| Error/disculpa | "Disculpá las molestias, estamos trabajando para solucionarlo" | "Error del sistema. Intente más tarde." |

**Registro lingüístico:**
- Usar **voseo** rioplatense: "vos podés", "contanos", "escribinos"
- Evitar el "usted" formal excepto en comunicaciones legales
- Usar vocabulario cotidiano argentino, no peninsular ni académico
- Permitir modismos locales con moderación ("te orientamos", "sin vueltas")

| Token CSS | Valor | Uso |
|-----------|:-:|-----|
| `--line-height-tight` | 1.25 | Headings (H1-H4), títulos cortos |
| `--line-height-normal` | 1.5 | Cuerpo de texto, párrafos, listas |
| `--line-height-relaxed` | 1.75 | Texto largo de lectura, artículos de blog |

### 3.4 Letter Spacing (Recomendaciones)

| Contexto | Valor | Notas |
|----------|-------|-------|
| Headings grandes (H1, H2) | `-0.02em` | Ajustar para que no se vea "abierto" |
| Headings medios (H3, H4) | `-0.01em` | Sutil compresión |
| Cuerpo de texto | `0em` (normal) | Inter ya está optimizada |
| Texto pequeño (xs, sm) | `0.01em` | Leve apertura para legibilidad |
| Botones / Labels | `0.02em` | Mejorar legibilidad en tamaños medianos |
| Todo mayúsculas | `0.05em – 0.1em` | Obligatorio para legibilidad |

### 3.5 Uso por Elemento HTML

```css
/* Headings — Outfit Bold, tight line-height */
h1 { font-family: var(--font-family-heading); font-size: var(--font-4xl); font-weight: 700; line-height: var(--line-height-tight); }
h2 { font-family: var(--font-family-heading); font-size: var(--font-3xl); font-weight: 700; line-height: var(--line-height-tight); }
h3 { font-family: var(--font-family-heading); font-size: var(--font-2xl); font-weight: 600; line-height: var(--line-height-tight); }
h4 { font-family: var(--font-family-heading); font-size: var(--font-xl);  font-weight: 600; line-height: var(--line-height-tight); }

/* Body — Inter Regular, normal line-height */
p    { font-family: var(--font-family-body); font-size: var(--font-base); font-weight: 400; line-height: var(--line-height-normal); }
li   { font-family: var(--font-family-body); font-size: var(--font-base); font-weight: 400; line-height: var(--line-height-normal); }
a    { font-family: var(--font-family-body); font-weight: 500; }

/* Small text — Inter, smaller sizes */
small   { font-size: var(--font-sm); }
caption { font-size: var(--font-xs); }
```

### 3.6 Estrategia de Carga de Fuentes

```typescript
// layout.tsx — Carga optimizada con next/font/google
import { Outfit, Inter } from "next/font/google";

const outfit = Outfit({
  variable: "--font-family-heading",
  subsets: ["latin"],
  display: "swap",                    // Evita FOIT
  weight: ["400", "500", "600", "700", "800"],
});

const inter = Inter({
  variable: "--font-family-body",
  subsets: ["latin"],
  display: "swap",
  weight: ["300", "400", "500", "600", "700"],
});
```

**Ventajas de `next/font/google`:**
- Self-hosted automáticamente (sin requests a Google Fonts)
- Zero layout shift (no CLS por carga de fuentes)
- `display: "swap"` muestra fuente del sistema hasta que carga la web font
- Solo descarga los pesos especificados (ahorro de bandwidth)

| **Mar del Plata** | Costa, parques, rambla, paisajes locales | 🟢 Baja |
| **Comida y nutrición** | Platos saludables, mesa compartida | 🟢 Baja |

### 5.3 Qué Evitar

| ❌ Evitar | Por qué |
|-----------|---------|
| Estética clínica/hospitalaria | Genera ansiedad, no es el mensaje de "hogar" |
| Fotos de stock genéricas | Se perciben como falsas, sin conexión local |
| Imágenes con marcas de agua | Aspecto no profesional |
| Adultos mayores en actitud pasiva o triste | Refuerza estereotipos negativos |
| Fotos con iluminación fluorescente | Transmite frialdad e institucionalidad |
| Primeros planos de medicación/equipamiento | Deshumaniza, enfoca en la enfermedad |
| Imágenes con personas muy jóvenes como "ancianos" | Falta de autenticidad |

### 5.4 Especificaciones Técnicas

| Propiedad | Valor |
|-----------|-------|
| **Formato principal** | WebP (con fallback JPEG) |
| **Calidad WebP** | 80-85% (balance calidad/peso) |
| **Dimensiones máximas** | 1920×1080px (hero), 800×600px (cards), 400×400px (avatar) |
| **Peso máximo** | 200KB (hero), 100KB (card), 50KB (avatar) |
| **Responsive** | Usar `next/image` con `sizes` para servir tamaño adecuado |
| **Lazy loading** | Todas excepto above-the-fold (`priority={true}` para hero) |
| **Aspect ratios** | 16:9 (hero/banner), 4:3 (card), 1:1 (avatar), 3:2 (galería) |
